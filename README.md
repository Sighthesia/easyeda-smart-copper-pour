# 一键智能铺铜

一键智能铺铜是一个面向立创EDA PCB 编辑器的扩展，用来根据当前选中的焊盘集合快速生成、预览并应用铜皮骨架。

当前支持多种拓扑模式，适合在同网络多焊盘之间快速建立更规整的铺铜连接方案，减少手工布铜和反复试错的时间。

## 功能概览

- 在 PCB 页面基于选中的 Pad 自动生成铜皮骨架
- 支持 `Tree`、`Star`、`Daisy Chain` 三种拓扑模式
- 支持调整骨架宽度、间距等关键参数
- 支持预览、应用和清除预览
- 仅对同一网络、同一层的 Pad 集合执行规划，降低误操作风险

## 使用方法

### 1. 打开扩展菜单

在立创EDA PCB 编辑器顶部菜单中找到“一键智能铺铜”并打开面板。

### 2. 选择目标焊盘

在 PCB 中选中多个需要进行铜皮连接的 Pad。

使用前请确认：

- 所选 Pad 位于同一网络
- 所选 Pad 位于同一层
- 选择集合已经覆盖本次想要生成铜皮骨架的目标焊盘

### 3. 选择拓扑模式并调整参数

在面板中选择合适的拓扑模式，并根据布局情况调整宽度、间距等参数。

常见选择建议：

- `Tree`：适合存在主干与分支关系的连接场景
- `Star`：适合从一个中心点向外分发的连接场景
- `Daisy Chain`：适合串联式依次连接的场景

### 4. 预览生成结果

点击预览后，扩展会在当前 PCB 环境中生成临时结果，帮助你检查路径、覆盖范围和间距效果是否符合预期。

### 5. 应用或清除预览

确认预览无误后点击应用，将结果写入当前设计。

如果效果不满意，可以先清除预览，再重新调整参数和拓扑模式后继续尝试。

## 适用场景

- 同一网络多个焊盘需要快速建立铜皮主干
- 需要在不同拓扑之间快速比较效果
- 想先预览铺铜结构，再决定是否真正写入 PCB
- 批量处理规则较清晰的 Pad 连接关系

## 已知限制

- 当前仅面向 PCB 编辑器页面
- 仅支持同一网络、同一层的 Pad 选择集合
- 实际 `Region` / `Pour` 行为仍可能受 EasyEDA BETA API 行为影响

## 构建与安装

```shell
npm install
npm run build
```

构建完成后，可在 `build/dist/` 目录中找到生成的 `.eext` 文件，并在立创EDA中安装测试或上传发布。

## 开发

- 编译源码：`npm run compile`
- 运行测试：`npm test`
- 格式化与修复：`npm run fix`
- 编译并打包：`npm run build`
