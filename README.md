# 一键智能铺铜

选中多个焊盘可一键使用多种拓扑方式生成规范的铺铜区域。

![一键智能铺铜示例](./images/2026-03-31%2018-43-45-00.00.02.000-00.00.16.563.gif)

## 功能概览

- 在 PCB 页面基于选中的 Pad 自动生成铜皮骨架
- 支持星形和菊花链拓扑模式
- 支持调整骨架宽度、间距等关键参数
- 支持预览、应用和清除预览

## 使用方法

### 1. 打开扩展菜单

在立创EDA PCB 编辑器顶部菜单中找到“一键智能铺铜”并打开面板。

### 2. 选择目标焊盘

在 PCB 中选中多个需要进行铜皮连接的焊盘。

### 3. 选择拓扑模式并调整参数

在面板中选择合适的拓扑模式，并根据布局情况调整宽度、间距等参数。

### 4. 预览生成结果

点击预览后，扩展会在当前 PCB 环境中生成临时结果，帮助你检查路径、覆盖范围和间距效果是否符合预期。

### 5. 应用或清除预览

确认预览无误后点击应用，将结果写入当前设计。

如果效果不满意，可以先清除预览，再重新调整参数和拓扑模式后继续尝试。

## 已知限制

- 仅支持同一网络、同一层焊盘的选择
- 对于复杂布局，算法可能铺铜

## 构建与安装

```shell
npm install
npm run build
```

构建完成后，可在 `build/dist/` 目录中找到生成的 `.eext` 文件，并在立创EDA中安装测试或上传发布。

## 开发

- 编译源码：`npm run compile`
- 运行测试：`npm test`
- 格式化与修复：`npm run fix`
- 编译并打包：`npm run build`
