# 一键智能铺铜

用来快速生成、预览和应用铜皮骨架，支持快速生成菊花链，星形拓扑。

## 功能

- 选择同一网络、同一层的多个 Pad 后生成铜皮骨架
- 菊花链，星形拓扑。
- 支持配置铺铜区域宽度、间距等参数
- 支持预览、应用和清除预览

## 使用方式

1. 打开菜单。
2. 在 PCB 编辑器中选中同一网络、同一层的多个 Pad。
3. 选择拓扑模式并调整参数。
4. 预览结果。
5. 确认无误后点击应用。

## 构建与安装

1. 安装依赖。

```shell
npm install
```

2. 编译并打包扩展。

```shell
npm run build
```

3. 在 `./build/dist/` 中找到生成的 `.eext` 文件，并在嘉立创EDA中安装。

## 开发

- 编译源码：`npm run compile`
- 运行测试：`npm test`
- 格式化与修复：`npm run fix`
